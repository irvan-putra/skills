2D Anime Video with AI

A working toolbox for making anime with AI: agent skills that run the whole production, models for characters and keyframes, clip generators, inbetweening, voices, and the finishing pass. Sibling page: Motion & content creation.

Agent skills (public instruction packs an agent loads before a task)

These cover the full pipeline: script, character sheets, shots, generation, QA, edit. None are tested by us; read each repo's own examples and cost notes before spending credits.

agent skill

claude-make-an-anime

Claude Code plugin that turns a story into a finished anime: character sheets, camera-directed shots, voices, a score, titles, subtitles and finishing VFX. Scales from a 12-second scene to a full episode. Paid generation goes through Fal, so it needs a Fal account with credit. MIT.

/plugin marketplace add makevoid/claude-make-an-anime
agent skill

anime-series-maker

Built for a series, not one-off clips: cast, style, voices and running gags live in a series bible so episode 30 looks like episode 1. Per-second shot scripts, prompt validation before any credit is spent, a cost gate that waits for your yes, per-clip QA, and an edit that survives Instagram. Claude Code / Codex. MIT.

git clone https://github.com/Mayzmei/anime-series-maker.git
agent skill

anime-video-production

Turns an anime-video brief into a reviewable film: shot direction, character-reference provenance, a Pika H3 Flex workflow on Colab/ComfyUI with budget checks, upscale comparison and delivery validation, plus a frame-aligned cutting helper with unit tests. New, small project. MIT.

npx -y skills add stevyhacker/anime-video-production-skill --skill anime-video-production --global
agent skill

animeblip-showrunner-skill

Lets any agent drive Animeblip's production pipeline (screenplay, consistent characters, scene videos, final cut, 900+ art styles) as its reviewer: you poll the session, critique, and fix single scenes instead of regenerating everything. Needs an Animeblip API key. MIT, vendor skill.

npx skills add animeblip-ai/animeblip-showrunner-skill
agent skill

animate

The code-drawn alternative: every frame is drawn procedurally on one canvas in a built-in style, or in a look matched from your own references, then rendered to MP4. Deterministic frames, no model drift, measured review checks. Not a diffusion workflow, but a real option for stylized 2D shorts. Our fork with fixes: irvan-putra/animate, demos at vanipy.com/animate.

/plugin marketplace add cth9191/animate

Characters & keyframes (image generation)

Consistency across a series comes from reference images, not from re-describing the character in every prompt: fix a character sheet once, then draw every shot from it.

service

PixAI

Anime-specialized image generator with its own model library and LoRAs; character design, manga and poster workflows. Free tier.

PixAI API (REST, key issued by request): submit a task, then poll it. Source: platform.pixai.art docs.

curl -X POST https://api.pixai.art/v2/image/create -H "Authorization: Bearer $PIXAI_API_KEY" -H "Content-Type: application/json" -d '{"modelVersionId":"MODEL_VERSION_ID","prompt":"an anime girl in a sunflower field","aspectRatio":"3:5"}'
service

NovelAI

Anime image generation plus storytelling tools; subscription service with its own anime-tuned models.

open model

Animagine XL 4.0

The most-downloaded open anime checkpoint (SDXL, text-to-image). Runs locally or in ComfyUI. OpenRAIL++ license; check its use restrictions.

git clone https://huggingface.co/cagliostrolab/animagine-xl-4.0
open model

Illustrious

Open anime SDXL base model that many community fine-tunes build on. Own license ("other" on Hugging Face); check terms before commercial use.

git clone https://huggingface.co/OnomaAIResearch/Illustrious-xl-early-release-v0
tool

ComfyUI

Node-based local pipeline that runs the open image and video models: keyframes, LoRA character consistency, upscaling and video workflows in one graph. GPL-3.0. comfy.org

git clone https://github.com/Comfy-Org/ComfyUI

Clip generators (text or keyframes to video, hosted)

Each generation is one shot of roughly 5 to 30 seconds depending on the service; an episode is dozens of shots assembled in an edit. Free allowances and prices change monthly, so confirm on each site.

service

Vidu

ShengShu's generator and the one that markets anime directly: reference-to-video keeps a character across clips, and the current Q4 model generates sound with the picture. Anime creators feature on its front page.

Vidu MCP server for Claude or Cursor (needs a Vidu API key with purchased API credits; the API host value is in the MCP guide on platform.vidu.com).

VIDU_API_KEY=your-key VIDU_API_HOST=api-host uvx vidu-mcp
service

Kling AI

Kuaishou's generator (VIDEO 3.0 and Omni live, 4.0 announced). Elements register a character from photos or video; Canvas adds an agent mode for scripts and storyboards, and MCP / CLI access lets an agent batch-produce clips.

Official Kling CLI (global accounts; China accounts use a different package). Log in, then run kling who_am_i to see live models. Source: npm @klingai/cli-global.

npm i -g @klingai/cli-global
kling login
kling who_am_i

Official Kling plugin for Claude Code (then authenticate the kling-ai server with /mcp). Source: klingai-tech/claude-plugin.

claude plugin marketplace add klingai-tech/claude-plugin
claude plugin install kling-ai@klingai
service

Hailuo AI

MiniMax's H3 model: up to twelve reference files (images, video, audio), clips up to 15 seconds at up to 2K, native sound.

MiniMax official CLI (needs a MiniMax Token Plan). Source: MiniMax-AI/cli.

npm install -g mmx-cli
mmx auth login
mmx video generate --model MiniMax-H3 --prompt "Ocean waves at sunset" --download clip.mp4
service

PixVerse

Fast text-and-photo to video (current model V6), aimed at quick social clips; cheap way to test ideas before committing a workflow.

Official PixVerse CLI. Source: PixVerseAI/cli.

npm install -g pixverse
pixverse auth login
pixverse create video --prompt "A cat walking on Mars" --model v6 --quality 720p --aspect-ratio 16:9
service

Runway

General creative suite plus API: generation, editing, performance-driven characters and lip-sync tools in one workspace. Suits people who edit their own film.

Runway API SDKs (create a key in the Runway developer portal and set RUNWAYML_API_SECRET). Source: docs.dev.runwayml.com.

pip install runwayml
npm install --save @runwayml/sdk
service

LTX Studio

Script to scenes, storyboard and timeline, with Elements for recurring characters and locations. Genre-agnostic, useful for planning an anime storyboard even if the final look comes from elsewhere.

The LTX API is a separate developer product from the LTX Studio app (key from the LTX Developer Console). Source: docs.ltx.io quick start.

curl -X POST https://api.ltx.io/v2/text-to-video -H "Authorization: Bearer YOUR_API_KEY" -H "Content-Type: application/json" -d '{"prompt":"A majestic eagle soaring through clouds at sunset","model":"ltx-2-5-pro","duration":8,"resolution":"1920x1080"}'
service

Animey

Purpose-built for anime series: you approve a six-view reference sheet per character once, every shot is drawn from it as a keyframe before motion, and episodes render with voices, music and subtitles. Original characters only; it refuses existing franchises and real people.

Anime motion tech (open source)

open model

ToonCrafter

Generative cartoon inbetweening: give it a start and end keyframe and it draws the motion between them, the closest thing to an AI assistant animator. SIGGRAPH Asia 2024. Apache-2.0. Project page, ComfyUI wrapper.

git clone https://github.com/Doubiiu/ToonCrafter
tool

Practical-RIFE

Frame interpolation: smooths animation drawn on 2s or 3s to higher frame rates, or retimes clips in the finishing pass. Actively maintained. MIT.

git clone https://github.com/hzwer/Practical-RIFE
open model

AnimateDiff

The original motion module that animates Stable Diffusion images without per-model training; older (2023 era) but still common in ComfyUI anime workflows. Apache-2.0.

git clone https://github.com/guoyww/AnimateDiff
open model

Pika H3 Flex

Open inference code for Pika's H3 video-and-audio generation model; the generator behind the anime-video-production skill's Colab/ComfyUI workflow. Own license, not a standard SPDX one; read its terms before commercial use.

git clone https://github.com/Pika-Labs/Pika-H3-Flex

Edit, subtitles, export → Motion page

The generic production pipeline (FFmpeg for the edit and loudness, WhisperX for timed subtitles, beat sync for music cuts, frame review loops) is documented on the Motion & content creation page and applies unchanged to anime.

How these fit together

  1. Series bible: fix the cast sheets, art style and voices once (anime-series-maker, Animey), so every episode reuses them.
  2. Keyframes: generate character sheets and shot stills (PixAI, NovelAI, or Animagine / Illustrious in ComfyUI) and approve them before paying for any motion.
  3. Motion, one shot at a time: image-to-video clips (Vidu, Kling, Hailuo) or keyframe inbetweening (ToonCrafter); each shot stays within the generator's clip limit.
  4. Voices: cast one voice per character (GPT-SoVITS, Style-Bert-VITS2, ElevenLabs) and keep it fixed for the series.
  5. Edit: join normalized clips, add music and sound, set loudness (the skills above automate this with FFmpeg).
  6. Finish: upscale (Real-ESRGAN, waifu2x), smooth motion (RIFE), subtitle (WhisperX).
  7. Review: watch the assembled cut; regenerate a failed clip whole rather than patching it (anime-series-maker's QA rule), and keep human review as the final gate.
