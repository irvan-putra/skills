Motion & Content Creation Skills

A working toolbox for making videos and other visual content: installable agent skills, animation and 3D libraries, and the production pipeline around them.

Agent skills (installable instruction packs for coding agents)

Each of these is a real, public skill package an agent can load before starting a task.

agent skill

motion-design-skill

Motion design principles for agents: timing, easing, choreography, and Disney's 12 animation principles adapted for UI. Implementation-agnostic (CSS, Motion, GSAP, Lottie, springs). MIT.

npx skills add LottieFiles/motion-design-skill
agent skill

Remotion Skills

Remotion's official skill set (14 skills) that teaches agents to create, preview and render videos: best practices, markup, rendering, studio control. Listings.

npx skills add remotion-dev/skills
agent skill

hairline

Isometric line art that reacts to the pointer. hairline-create draws a figure from an idea; hairline-adopt rebuilds an existing SVG on the same engine. Output is a single HTML file. MIT. Docs.

npx skills add lucasmarkes/hairline
agent skill

anatomy

Interactive isometric SVG diagrams that explain a technical idea as a real physical object or machine, with optional WebGL shaders and a beta true-3D mode. Author's page.

agent skill

anatomy-reveal

Builds an object (product, tool, instrument) as a many-part isometric figure, then produces an exploded-view reveal film and an interactive dissection page. Works from a photo or a name. MIT.

Animation & 3D libraries

"With an agent" lines link to a real, public skill package or MCP server that teaches an agent to drive that tool.

library

Motion

Spring motion and screen transitions for React and JavaScript (formerly Framer Motion). The default choice for UI animation in React.

With an agent: Motion AI Kit, the official skill, MCP and docs pack from the Motion team.

npx motion-ai
library

GSAP

Timeline-based animation for the web. Precise sequencing of many elements, scroll triggers, SVG morphing.

With an agent: GSAP Skills, GreenSock's official skill set for coding agents.

npx skills add greensock/gsap-skills
library

Three.js

3D scenes and cameras in the browser. The base layer for WebGL content; pairs with react-three-fiber in React.

With an agent: threejs-skills, 13 skills teaching current three.js, WebGPU/TSL and react-three-fiber.

npx skills add cloudai-x/threejs-skills
library

react-three-rapier

Rapier physics in 3D React scenes: collisions, gravity, ragdolls. MIT.

With an agent: r3f-skills includes r3f-physics, a Rapier bodies-and-colliders skill.

npx skills add EnzeD/r3f-skills
library

react-postprocessing

Cinematic post effects for react-three-fiber: bloom, blur, depth of field, vignette.

With an agent: r3f-skills includes r3f-postprocessing, for composer pipelines and screen effects.

npx skills add EnzeD/r3f-skills
library

three.quarks

Particle effects for three.js: fire, smoke, explosions, magic. Batched rendering, Unity-Shuriken-style features. MIT. quarks.art

library

Tweakpane

Compact pane to adjust parameters live while developing a scene or animation.

desktop tool

Blender

Free and open source 3D suite: rigging and character animation, modeling, rendering. Export glTF for the web.

With an agent: Blender MCP, a community MCP server that lets an agent control Blender directly.

tool

Manim

Programmatic animation of diagrams, formulas and explainers, the style known from math channels. Python.

With an agent: manim-skill, an agent pipeline that turns ideas and math into Manim scenes. Apache-2.0.

npx skills add vumichien/manim-skill
library / format

Lottie

Lightweight vector animations exported from After Effects, played on web and mobile. Huge free library at LottieFiles.

With an agent: LottieFiles' official agent guide, creator.lottiefiles.com/agents.md, covers driving Lottie Creator from an agent, including its official MCP server.

library / engine

Remotion

Video engine in React: compositions, sequences, rendering to MP4. The foundation the Remotion skills teach agents to drive.

With an agent: the official Remotion Skills listed above.

npx skills add remotion-dev/skills

Production pipeline

API

Openverse API

Search openly licensed audio (SFX, music) and images. Free anonymous use; optional OAuth registration raises rate limits. Every asset carries its own license, so check the license and attribution requirements on each result before using it. Docs.

With an agent: mcp-openverse, a community MCP server for searching Openverse from an agent.

library

librosa

Python audio analysis: beat tracking and tempo detection to sync cuts and movement to music.

With an agent: mcp-music-analysis, a community MCP server that runs librosa analysis for an agent.

tool

WhisperX

Automatic subtitles with word-level timestamps and speaker diarization, fast batched inference. BSD-2-Clause.

With an agent: whisperx-transcribe, a skill that runs WhisperX and returns a speaker-labeled Markdown transcript.

npx skills add abubakarsiddik31/whisperx-transcribe
tool

FFmpeg

Export and conversion for everything: codecs, trimming, muxing audio and subtitles, thumbnails.

With an agent: ffmpeg-skill, vetted FFmpeg recipes plus a full production pipeline.

npx skills add muhammaddadu/ffmpeg-skill

How these fit together

  1. Principles: motion-design-skill sets timing, easing and intent before any code.
  2. Build: Remotion (with its official skills) for video; Three.js + rapier + postprocessing + quarks for interactive 3D; hairline, anatomy, anatomy-reveal for line art and object explainers; Manim for formulas; Lottie for light vector loops.
  3. Audio: find licensed SFX and music through the Openverse API.
  4. Sync: librosa detects beats so cuts and movement land on the music.
  5. Subtitles: WhisperX generates timed captions.
  6. Export: FFmpeg converts and packages the final files.
