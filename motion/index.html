Motion & Content Creation Skills

A working toolbox for making videos and other visual content: installable agent skills, animation and 3D libraries, the production pipeline around them, and loops that review the render.

Agent skills (installable instruction packs for coding agents)

Each of these is a real, public skill package an agent can load before starting a task.

agent skill

motion-design-skill

Motion design principles for agents: timing, easing, choreography, and Disney's 12 animation principles adapted for UI. Implementation-agnostic (CSS, Motion, GSAP, Lottie, springs). MIT.

npx skills add LottieFiles/motion-design-skill
agent skill

Remotion Skills

Remotion's official skill set (14 skills) that teaches agents to create, preview and render videos: best practices, markup, rendering, studio control. Listings.

npx skills add remotion-dev/skills
agent skill

hairline

Isometric line art that reacts to the pointer. hairline-create draws a figure from an idea; hairline-adopt rebuilds an existing SVG on the same engine. Output is a single HTML file. MIT. Docs.

npx skills add lucasmarkes/hairline
agent skill

anatomy

Interactive isometric SVG diagrams that explain a technical idea as a real physical object or machine, with optional WebGL shaders and a beta true-3D mode. Author's page.

agent skill

anatomy-reveal

Builds an object (product, tool, instrument) as a many-part isometric figure, then produces an exploded-view reveal film and an interactive dissection page. Works from a photo or a name. MIT.

Animation & 3D libraries

"With an agent" lines link to a skill (an instruction pack the agent loads) or an MCP server (live tool access for the agent) that helps it drive that tool. Paid entries are labeled, with verified free alternatives listed alongside.

library

Motion

Spring motion and screen transitions for React and JavaScript (formerly Framer Motion). The default choice for UI animation in React.

With an agent: Motion AI Kit (skill + MCP server), the official pack from the Motion team with current docs.

npx motion-ai
library

GSAP

Timeline-based animation for the web. Precise sequencing of many elements, scroll triggers, SVG morphing.

With an agent: GSAP Skills (skill), GreenSock's official skill set for coding agents.

npx skills add greensock/gsap-skills
library

Three.js

3D scenes and cameras in the browser. The base layer for WebGL content; pairs with react-three-fiber in React.

With an agent: threejs-skills (skill collection), 13 packs covering current three.js, WebGPU/TSL and react-three-fiber.

npx skills add cloudai-x/threejs-skills
library

react-three-rapier

Rapier physics in 3D React scenes: collisions, gravity, ragdolls. MIT.

With an agent: r3f-skills (skill collection) includes r3f-physics, a Rapier bodies-and-colliders pack.

npx skills add EnzeD/r3f-skills
library

react-postprocessing

Cinematic post effects for react-three-fiber: bloom, blur, depth of field, vignette.

With an agent: r3f-skills (skill collection) includes r3f-postprocessing, for composer pipelines and screen effects.

npx skills add EnzeD/r3f-skills
library

three.quarks

Particle effects for three.js: fire, smoke, explosions, magic. Batched rendering, Unity-Shuriken-style features. MIT. quarks.art

With an agent: three.quarks VFX (skill, paid: download requires an AdAnt subscription, from $15/month).

Free alternatives: the three.quarks repo itself is MIT and ships docs plus live examples an agent can read and follow directly. For a free skill, Threejs Awesome Graphics Agent Skills (MIT) has a procedural-vfx pack for hand-rolled effects; that is a broader route, not a particle-engine replacement for quarks.

library

Tweakpane

Compact pane to adjust parameters live while developing a scene or animation.

With an agent: Tweakpane Live Tuning (skill, paid: download requires an AdAnt subscription, from $15/month).

Free alternatives: Tweakpane itself is free (MIT) and its docs are short enough for an agent to read cold. For a free skill, tuning-panel builds a Tweakpane, Leva or dat.GUI panel and exports the tuned values back for the agent; a small project with no license file, unlike the paid skill's scripted-mouse demo loop.

API

Openverse API

Search openly licensed audio (SFX, music) and images. Free anonymous use; optional OAuth registration raises rate limits. Every asset carries its own license, so check the license and attribution requirements on each result before using it. Docs.

With an agent: mcp-openverse (MCP server), a community server for searching Openverse from an agent.

With an agent: mcp-music-analysis (MCP server), a community server that runs librosa analysis for an agent.

Review & feedback loops (checking what actually rendered)

Making the thing is half the job; the other half is looking at what came out. These close that loop: they capture frames, check them against the brief or your pinned comments, and feed fixes back for another pass. One caution: these projects describe feedback workflows, not proof that they catch every defect or reliably flag unnatural, uncanny valley looking output. We have not installed or tested them here, so human review remains the final gate.

agent skill

frame-judge

A critic loop where the builder never grades its own work: build and render, capture screenshots and frame sheets, then a separate code-blind critic agent judges only the pixels against the user's original request, with a capped revise loop. For UI, animation and video; runs in Claude Code, Cursor, Codex, ChatGPT and Antigravity. Apache-2.0. New, small project.

tool + skill

FrameJam

Human feedback by pointing: pause the render, click the frame and the exact spot that is off, write the note, and the agent gets timestamped comments with pinned frames and revises round by round. Plugin for Claude, ChatGPT and Cursor; local-first, works with any tool that renders MP4, over MCP. MIT. framejam.ai

agent skill

claude-motion review-loop

A motion-design toolkit for coding agents whose review-loop skill renders a draft, tiles one frame per timeline beat into labeled contact sheets, and checks composition, type, timing and consistency against a checklist before the video is called done. Self-review by the same agent, so pair it with your own look. MIT.

MCP servers

Playwright MCP / Chrome DevTools MCP

The capture plumbing behind web review loops: let an agent drive a real browser, screenshot pages and capture animation states, so there are actual frames to judge. Official servers from Microsoft and Google, both Apache-2.0.

How these fit together

  1. Principles: motion-design-skill sets timing, easing and intent before any code.
  2. Build: Remotion (with its official skills) for video; Three.js + rapier + postprocessing + quarks for interactive 3D; hairline, anatomy, anatomy-reveal for line art and object explainers; Manim for formulas; Lottie for light vector loops.
  3. Audio: find licensed SFX and music through the Openverse API.
  4. Sync: librosa detects beats so cuts and movement land on the music.
  5. Subtitles: WhisperX generates timed captions.
  6. Export: FFmpeg converts and packages the final files.
  7. Review: before calling it done, look at the render: frame-judge checks the frames against the brief, FrameJam collects your pinned comments, then revise and check again.
