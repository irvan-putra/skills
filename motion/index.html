Motion & Content Creation Skills

A working toolbox for making videos and other visual content: installable agent skills, animation and 3D libraries, the production pipeline around them, and loops that review the render.

Agent skills (public instruction packs an agent loads before a task)

agent skill

motion-design-skill

Motion design principles for agents: timing, easing, choreography, Disney's 12 principles adapted for UI. Works with CSS, Motion, GSAP, Lottie, springs. MIT.

npx skills add LottieFiles/motion-design-skill
agent skill

Remotion Skills

Remotion's official skill set (14 skills) for creating, previewing and rendering videos. Listings.

npx skills add remotion-dev/skills
agent skill

hairline

Isometric line art that reacts to the pointer. hairline-create draws a figure from an idea; hairline-adopt rebuilds an existing SVG. Output is a single HTML file. MIT. Docs.

npx skills add lucasmarkes/hairline
agent skill

anatomy

Interactive isometric SVG diagrams that explain a technical idea as a real physical object or machine, with optional WebGL shaders and a beta true-3D mode. Author's page.

npx skills add wheresryan22/anatomy
agent skill

anatomy-reveal

Builds an object as a many-part isometric figure, then produces an exploded-view reveal film and an interactive dissection page. Works from a photo or a name. MIT. TypingMind listing.

npx skills add annnguyentt/anatomy-reveal-skill

Animation & 3D libraries

"With an agent" lines link a skill (an instruction pack the agent loads) or an MCP server (live tool access) that helps an agent drive that tool. A code line appears when the project has a single install command.

three.quarks

Compact pane to adjust parameters live while developing a scene or animation. MIT.

Production pipeline

API

Openverse API

Search openly licensed audio (SFX, music) and images. Free anonymous use; optional OAuth registration raises rate limits. Check each result's own license and attribution requirements. Docs.

With an agent: mcp-openverse, a community MCP server for searching Openverse.

library

librosa

Python audio analysis: beat tracking and tempo detection to sync cuts and movement to music. librosa.org

With an agent: mcp-music-analysis, a community MCP server that runs librosa analysis.

tool

WhisperX

Subtitles with word-level timestamps and speaker diarization, fast batched inference. BSD-2-Clause.

With an agent: whisperx-transcribe, runs WhisperX and returns a speaker-labeled Markdown transcript.

npx skills add abubakarsiddik31/whisperx-transcribe
tool

FFmpeg

Export and conversion for everything: codecs, trimming, muxing audio and subtitles, thumbnails. ffmpeg.org

With an agent: ffmpeg-skill, FFmpeg recipes plus a full production pipeline.

npx skills add muhammaddadu/ffmpeg-skill

Review & feedback loops (checking what actually rendered)

These capture the render, check it against the brief or your pinned comments, and feed fixes back for another pass. They describe feedback workflows, not proof that they catch every defect or reliably flag unnatural, uncanny valley looking output. None are tested here, so human review stays the final gate.

agent skill

frame-judge

A separate code-blind critic agent judges captured screenshots and frame sheets against your original request, with a capped revise loop. For UI, animation and video; runs in Claude Code, Cursor, Codex, ChatGPT and Antigravity. Apache-2.0. New, small project.

git clone https://github.com/mirac221/frame-judge && node frame-judge/scripts/install.mjs
tool + skill

FrameJam

Pause the render, pin a comment to the exact frame and spot that is off, and the agent revises round by round. Plugin for Claude, ChatGPT and Cursor; local-first, works with any tool that renders MP4, over MCP. MIT. framejam.ai

npx -y framejam install
agent skill

claude-motion review-loop

A motion-design toolkit whose review-loop skill renders a draft, tiles one frame per timeline beat into labeled contact sheets, and checks composition, type, timing and consistency against a checklist. Self-review by the same agent, so pair it with your own look. MIT.

MCP servers

Playwright MCP / Chrome DevTools MCP

The capture plumbing behind web review loops: an agent drives a real browser, screenshots pages and captures animation states, so there are actual frames to judge. Official servers from Microsoft and Google, both Apache-2.0.

How these fit together

  1. Principles: motion-design-skill sets timing, easing and intent before any code.
  2. Build: Remotion (with its official skills) for video; Three.js + rapier + postprocessing + quarks for interactive 3D; hairline, anatomy, anatomy-reveal for line art and object explainers; Manim for formulas; Lottie for light vector loops.
  3. Audio: find licensed SFX and music through the Openverse API.
  4. Sync: librosa detects beats so cuts and movement land on the music.
  5. Subtitles: WhisperX generates timed captions.
  6. Export: FFmpeg converts and packages the final files.
  7. Review: frame-judge checks the frames against the brief, FrameJam collects your pinned comments, then revise and check again.
